# Supabase target-model contract v1

contract_version: supabase-target-model-v1

This reviewed U1 contract governs every current array, JSON column, and
polymorphic/JSON-backed relation. It does not create the target tables. U4-U6
must either implement the named model or version this contract with review.
Every target key is parent-qualified so a child cannot cross editorial,
member-lifecycle, brokerage-account, or immutable-generation boundaries.

## Polymorphic relationships

| Current fields | Target/cardinality and parent key | Lifecycle, order, nullability, uniqueness and deletion | Backfill / authority / consumer |
|---|---|---|---|

Saved/member API reads typed target. |
| `saved_items(source_kind,source_id)` | Nullable typed attribution relation parented by the save key | Source pair both null or both valid; no cross-kind IDs; attribution deletion sets null only when product contract permits | Map known sources; unknown becomes quarantined metadata, never authority. | `admin_audit_events(target_kind,target_id)` | Immutable versioned audit subject envelope; 0..1 live link plus required target type and redacted fingerprint | Not lifecycle authority; nullable live FK; audit event immutable and retained if target deleted | Existing rows keep redacted target/fingerprint. | `outbox_events(event_type,aggregate_id)` | Versioned event registry plus typed event-subject mapping; exactly one aggregate | Event owner lifecycle nullable only for provider-neutral purge; deterministic `(event_type,aggregate_id,dedupe_key)`; subject deletion cannot erase required durable work | Map every current event through one generated SQL/TS registry. | `aggregate_consumer_watermarks(aggregate_kind,aggregate_id)` | Registry-backed stream key; one watermark per consumer/aggregate | Required kind/id; monotonic version; retain with stream or purge by registry owner | Backfill known kinds; unknown quarantined. Worker observability only. |
| `member_idempotency_records(operation,resource_id)` | Versioned operation registry and typed optional result link | Key includes immutable member lifecycle; resource nullable until complete; unique lifecycle+operation+key; delete/expire by lifecycle and TTL | Backfill current operation mappings. Backfill via provider-contract parser. Brokerage read API. |

reviewer never has to infer cardinality, lifecycle, deletion, backfill, or
consumer semantics from classification alone.
