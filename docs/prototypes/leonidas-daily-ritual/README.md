# Leonidas Daily Ritual prototype

This directory preserves the selected mobile choreography that was approved on
September 2, 2026:

1. Leonidas enters as a full-body, standing presence.
2. He summons and flips the assigned tarot card.
3. After the card face is visible, the scene transitions to his close-up.
4. The close-up carries the spoken interpretation and evidence invitation.

Open `index.html` to compare the selected A+B sequence with the two rejected
directions. The browser voice is a placeholder for the native Flutter voice
bridge; captions and safety language are part of the retained behavior.

The images in `img/` are retained with the artifact so this exact prototype is
self-contained. The canonical source images and character specification remain
under `ritual-investing-app/assets/images/leonidas/`.

See `decisions.md` for the product decision and production follow-ups.
